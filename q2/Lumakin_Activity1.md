1. What is/are the parent class/es of the Programmer class in the video?
The parent class of Programmer is Employee, and Employee inherits from the Person class. Therefore, Person is the indirect parent class of Programmer. 

(videodb.org)

2. If you were to add a new role called Intern, where would you place it in the inheritance hierarchy? Why?
I would place Intern under the Employee class, alongside Programmer, Manager, and Cleaner. This is because an intern is also a type of employee and can inherit common properties and methods from the Employee class, avoiding code duplication.
