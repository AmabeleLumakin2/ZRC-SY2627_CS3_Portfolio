1. What do all the methods (move(), special_move(), use()) in the previous activities have in
common?
All the methods move(), special_move(), and use() have in common is that they represent the actions or behaviors of objects, and they can demonstrate polymorphism because the same method name can perform different actions depending on the object calling it, dame name different behavior.

2. How does this activity show polymorphism in a gaming context?
This activity shows polymorphism because different game items or functiosn have the same method, like use(), but have different actions depending on which item is used. Just like in the activity, a Health Potion restores HP, a Mana Potion restores MP, and a Speed Boost increases the player's speed.
